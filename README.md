This is a simple project- a simulation for a Hospital Management System Webapp. This will support 3 sides- the customer or the patient side, the doctors side and the admin side.
All sides have Tabbed Interfaces.

1. The patients will be able to see options like account, security, tickets, schedule and an option to create a new appointment.
2. The doctors will be able to see options like their acc, sec, their patients and their reports, schedules, and book appointments with the patients.
3. The admins will be able to add/remove/modify databases for patients or doctors..
   "Will fall under Naive/Parametric Users of DB"
